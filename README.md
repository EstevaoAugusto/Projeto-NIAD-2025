# Projeto-NIAD-2025
Projeto realizado em equipe como trainees no processo seletivo para o NIAD (Núcleo de Estudos em Inteligência Artificial e Data Science), onde desenvolvemos uma IA para o Jogo da Velha, por meio do algoritmo MinMax, que é impossível de ser vencida e demonstramos quantitativamente o ganho de eficiência computacional ao usar a otimização Poda Alfa-Beta.
